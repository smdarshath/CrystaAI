# Phone companion

Status: **native Android app is planned, not built.**

What works today: pair a phone with Crysta (Devices → Create pairing code), then use Crysta from the phone's browser (chat + research).
A paired phone cannot control the computer unless you explicitly allow it per device, and each action still needs approval on the computer.

Planned native app (not implemented): notifications forwarding, share-to-Crysta, deep links. Android does not allow unrestricted remote control; anything deeper would need Accessibility permission with clear consent.

# Research & YouTube

**Sources (free, no keys):** DuckDuckGo HTML results; the top *relevant* pages are fetched and reduced to text. Results are ranked official-first (.gov/.edu/.int/.ac.in…, then organisations whose name matches the topic, then others; forums/social are down-ranked) and results unrelated to the question are dropped. **Wikipedia is never primary:** it is added only as labelled *background* when fewer than two real pages could be read, and it cannot make a result 'success'. For competitions/scholarships the search adds the current year, 'official' and 'registration deadline', and the answer lists deadline sentences, registration/apply links found on the pages, whether each page mentions the current year, and whether sources disagree on dates. These are unofficial/free endpoints: they can rate-limit, change format or block. When that happens Crysta says so and still uses whatever provider worked; if everything fails it returns **no answer rather than a made-up one**.

**Answer format:** Direct answer → Key findings → Comparison → Limitations → Sources, with `[n]` markers tied to the clickable source list. Without a language model the text is extracted sentences (scored by overlap with your question). With Ollama, the model writes the synthesis from the same numbered sources and the result is labelled as model-written.

**YouTube:** search results give titles/channels/durations (*metadata only*). "What is he saying in that video" tries the video's own captions (uploaded or auto-generated). If captions aren't available, the answer says it only has the title/channel. Videos are never downloaded. "…and verify" compares caption passages with web pages using a **keyword-overlap heuristic**, labelled as not true fact-checking.

**Testing status:** parsers and logic are tested against saved fixtures. Live requests could not be exercised in the build environment (no network) — run the app online once and try "research black holes" to confirm on your machine. YouTube changes its pages often; if search or captions stop working, that's where to look (`crysta/tools/youtube_research.py`).

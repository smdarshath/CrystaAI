# Desktop companion

Status: **not needed yet.** When Crysta runs on your laptop it controls that laptop directly (VEGA agent, permission-gated).
A separate companion would only be needed to control a *second* computer from this one. That is planned, not built.
Design when built: a small service on the other computer exposing a narrow, token-authenticated API (open app, list approved folder, run allow-listed command) — never a raw remote shell.
